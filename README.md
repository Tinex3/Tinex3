- 🐍 Backend en **Python (Flask, FastAPI)**: APIs REST, lógica de negocio y comunicación con dispositivos
- ⚛️ Frontend en **React / TypeScript** para visualización en tiempo real
- ☁️ Infraestructura en **AWS con Docker y Linux**

Me especializo en conectar software, hardware y nube en un solo sistema.
